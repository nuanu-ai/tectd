# Compare options and trade-offs

Use at B06 with the current criteria, option set and evidence checkpoint. Exclude stale outputs. Compare alternatives against the same constraints, horizon and baseline.

First check eligibility under hard constraints, citing the premise or evidence that makes an option pass, fail or conditional. Then compare the viable options on the actual criteria. Explain the mechanism behind each benefit and cost, dependencies and interactions, reversible versus irreversible commitments, downside exposure and cost of being wrong. Avoid comparing a detailed realistic option with an idealized alternative.

Recommend a direction with clear reasons. Distinguish measured facts, bounded estimates, qualitative judgments and owner preferences. Use numerical scoring only when measurements/weights are justified and the ranking is meaningful; do not invent precision or allow an arbitrary total score to hide a violated constraint.

Test sensitivity: identify the assumption, estimate or priority at which the recommendation changes. State which uncertainties can be carried as conditions, which call for a reversible first step and which prevent selection. A conditional recommendation should specify the condition and alternative, not present ambiguity as certainty.

Write `option-comparison.md` with eligibility, criterion-by-option comparison, important trade-offs, recommendation, strongest alternative, sensitivity/change triggers, irreversible consequences and residual questions. Set `recommendation`, `sensitivity` and `irreversible_consequences`.

Return to B03/B04/B05 for a missing criterion, overlooked option or decisive evidence. Do not dispatch implementation or research implicitly. This phase produces a reasoned proposal for challenge and disposition, not an execution authorization.
