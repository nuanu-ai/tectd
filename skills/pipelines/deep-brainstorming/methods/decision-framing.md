# Decision framing

Use at B01 to state which choice must be resolved and for whom. Read the native inquiry boundary, immutable topic/completion contract, parent intent and existing user decisions.

Restate the problem in terms of the outcome and people affected, not a preselected solution. Identify the decision owner, intended consumer, present situation, reason to decide, decision horizon, scope/non-goals and what a useful result looks like. Separate facts already established, choices already made, open preferences and assumptions. A request for recommendations is different from authority to select and execute an option.

Use available context before asking. Ask for an essential missing preference or boundary with a concise, answerable question; several connected unknowns can be grouped when that reduces burden. Do not restart an already approved discussion or require another approval because a reference skill has a default ritual. If the user delegated the choice, exercise that authority within its limits and record the basis.

Match the topic level. A strategic Program question should first expose goals and structural constraints; a Scope question boundaries and dependencies; a specific Slice question the detail necessary to choose. Scope a large conversation around a meaningful decision rather than creating endless exploration. Split genuinely independent outcomes when they can be decided separately, preserving their relation.

Produce `decision-brief.md` with the decision question, purpose, owner/authority, audience, present baseline, scope/non-goals, known decisions, unresolved questions, success criterion, time/context boundary and stop/resume conditions. Set `topic_level`, `requested_outcome`, `decision_question`, `decision_owner` and `scope_boundary` consistently with the immutable inquiry.

Proceed when later phases can compare options without inventing intent. Missing essential intent or authority is WaitingInput with the exact question and resume condition. A changed completion objective requires explicit new work; it cannot be hidden in the final memo.
