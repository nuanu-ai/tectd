# Research work and custody plan

Use at R04 to turn the evidence plan into accountable bounded passes. Solo is the normal complete route under the user's intellectual-work policy; the word assignment does not imply subagent dispatch.

Read R01–R03. Partition work only where question groups, source families, access/freshness conditions or contradiction probes need a distinct pass. Each unit records task ID, objective, question IDs, source partition, allowed reads, exclusions, dependencies, expected artifact/evidence shape, proof requirement, sensitivity, budget, stop/resume condition and fan-in owner. Every question and source family maps to a unit or a declared gap. Avoid unnecessary decomposition of a simple sequential investigation.

Assign each unit to the primary agent unless delegation is explicitly permitted for this task. If permitted help is useful, identify the actual authority, bounded packet, output location, source limits and return contract. A planned assignee is not a dispatched or completed worker. Overlap needs a primary source owner, citation namespace and conflict/merge rule; duplicate independent-looking reports cannot multiply one source's evidential weight.

Define custody before collection: stable source/evidence IDs, exact locators and versions, raw versus derived records, collection timestamp, source date, collector, source owner or explicit unknown, safe citation/paraphrase, allowed use, sensitivity, retention, freshness/provenance notes, negative searches, contradictions and gaps. Returned reports are evidence pointers awaiting qualification, not accepted facts. Preserve inaccessible/restricted/rejected material as safe gap records instead of losing it at fan-in.

Write `task-decomposition.md` with task coverage, ordering, source partitions, proof matrix, risks and merge points. Write `work-assignments.md` with owner/pass, execution mode, scope, overlap rules, evidence-return schema, expected returned work and intake/fan-in procedure. Set `execution_mode` to `solo` or `explicitly_authorized_delegation`, with authority stated in the latter case; set `custody_contract` and `assignment_coverage`.

Return to R03 if dependencies cycle or the source/authority/proof boundary needs redesign. Proceed to collection only when every unit has an owner or explicit blocked route. Do not collect sources, dispatch help, accept claims or publish knowledge merely to make this plan look complete.
