# Knowledge Change: prepare lossless semantic diff

Prepare typed operations against the exact baseline and qualified evidence. Model a unit as one independently applicable meaning, not one word/triple or an entire large document. Preserve complete material conditions, exceptions, modality, applicability, epistemic status and provenance. Use stable backend-issued identities; titles, file names and internal graph/dictionary IDs are not identity.

Show the before/after meaning for every operation. A cosmetic title edit does not authorize a changed norm. New claims or changed conditions require their own evidence trace. Keep unchanged material unchanged and show the exact basis for reuse. Source text and your interpretation remain distinguishable.

Create/revise produce immutable content revisions. Revalidate produces an evidence/freshness event only when the meaning remains unchanged. Supersede records explicit predecessor/successor and replacement bindings; self-links, cycles and unexamined scope expansion are invalid. Retract withdraws eligibility while preserving permitted history. Erase follows the precise reviewed copy scope and leaves only permitted tombstone metadata. Reactivation is an explicit reviewed revise, never deletion of a prior withdrawal event.

Prepare the common fields and every required typed profile section. Reference environment parameters and credential custody without secret values. Describe procedures and infrastructure without executing them. The backend validates and maps the typed payload into RDF; do not send arbitrary SQL/SPARQL or write a parallel canonical file.

Read the KC-05 branch of the advertised phase-completion schema for the operation and document layouts. Copy the exact ordered profiles from the qualified plan, including General, and fill their required sections. Public request arguments omit unused optional fields; explicit null is rejected. If an exact-read response contains null for an unused section, omit that field when constructing the request. This does not waive a selected profile's required section. Use only the reviewed exact sources. Caller-supplied `binding_pins` must be empty: the backend resolves the requested binding targets and pins their actual definitions before accepting the proposal. Preserve the supplied operation/unit identities and current guards. Computed changeset and evidence digest placeholders do not authorize inventing a digest or substituting a different source basis.

Return the proposed changeset and readable semantic diff with operation-to-evidence trace. If the change cannot be represented without loss, return the missing modeling decision instead of flattening it into generic prose or discarding requirements.
