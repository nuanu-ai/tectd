# Knowledge Change: operations and profile qualification

Classify the content and intended operation using the current baseline. General DK is mandatory for all knowledge. Procedure implies Runbook; protocol behavior implies Protocol; infrastructure object truth implies DevOps; operating models imply Operations; product evidence and conclusions imply Product Research; threat/control/authority knowledge implies Security. Multiple aspects may require multiple profiles. A role label does not waive a cross-domain restriction.

Explain each assignment. Preserve inherited target profiles; a type/domain change is itself a reviewed semantic change. Unknown type or required profile is classification_required/profile_missing, not permission to fall back to General. Profiles add obligations and never create independent canonical writers.

Inspect the backend-compiled branch plan: all operations, dependencies, profile/shapes/policy/method versions, required outputs, applicability and terminal rules must be covered. Request explicit requalification when they are wrong. An omitted branch is not a waiver. Use not_applicable only under the profile's declared condition and with a concrete reason.

Default whole delivery is appropriate for bounded ready inputs and known small checks. Choose phasewise for unresolved meaning, dependent reviews, material missing sources, large model change or complicated erasure/effects. Supply `phasewise_reason` on your phase output to request this one-way change explicitly. An accepted waiting, blocked or finding/rework checkpoint also records the reason and changes a whole run to phasewise. Whole still requires ordered reasoning over saved outputs. Resuming the same run does not switch it back to whole; do not ask for a human 'continue' between routine phases.

Return the operation/profile assessment, dependency rationale and delivery qualification, consuming the exact baseline. The backend creates and pins the plan; you do not supply fabricated digests or silently remove obligations.

Source: design §7.5, §7.9, §7.11–7.14.
